# Proyecto Montaje y Mantenimiento - Tienda Online de Accesorios de Moto

## Descripción
Este proyecto consiste en el diseño y planificación del hardware necesario para los equipos informáticos de una tienda online de accesorios para motociclistas.

## Contenido del proyecto
- Análisis de necesidades de hardware
- Configuración de un equipo informático
- Montaje del equipo
- Mantenimiento básico
- Inventario de equipos

## Configuración del equipo
Se ha propuesto un equipo equilibrado con procesador Intel i5, 16 GB de RAM y almacenamiento SSD, adecuado para tareas de oficina.

## Montaje
Se ha explicado el proceso de montaje del equipo, incluyendo la instalación de todos los componentes principales.

## Mantenimiento
Se han definido tareas de mantenimiento como limpieza, revisión de ventilación y sustitución de componentes.

## Inventario
Se ha elaborado un inventario de los equipos de la empresa para facilitar su gestión.
